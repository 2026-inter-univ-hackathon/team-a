## 動かし方

### 埋め込みプレイヤーで見せたいとき（任意）

`index.html` を直接開くと、YouTube のエラー153で埋め込み再生ができません
（Referer が無いページからの埋め込みは拒否されるため）。
その場合は「YouTube Music で開く」リンクを押すと別ウィンドウで再生できるので、**そのままでも使えます**
（自動では開きません。開くかどうかは人が決めます）。

画面の中の埋め込みプレイヤーで見せたいときだけ、このフォルダで次を実行してください。

```
python3 -m http.server
```

→ `http://localhost:8000/index.html` を開く

なお、権利者が埋め込みを禁止している曲（YouTube Music には多い）は、
この方法でもエラー153になります。その曲はリンクから別ウィンドウで再生してください。
