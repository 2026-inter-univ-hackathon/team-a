# matchon

部室で再生ボタンを押すだけ。好き・嫌い・今は違うという評価から好みを学習し、次に流す曲を自動で選ぶ音楽プレイヤー

## 何を作ったか
部室でBGMを流したい人の「次に何を流すか考える手間」を減らす音楽プレイヤーです。
曲を再生して、高評価・低評価・Skip の3つの反応をするだけで、その人の好みを学習します。
学習したデータをもとに、AIが次に流す曲を提案します。
「何を聴くか」という最後の判断は人間に残し、AIが勝手に再生し続けるのではなく、人間とAIが一緒に選曲することを目指しました。


## 使った技術

* HTML / CSS / JavaScript
* Python
* 機械学習
* JSON（楽曲データ・再生履歴・モデルデータの保存）
* Freesound API（音源・楽曲メタデータの取得）
* Git / GitHub

### 構成

フロントエンドには HTML / CSS / JavaScript、バックエンドには Python を使用しています。

Python サーバーが楽曲データや再生履歴を管理し、機械学習モデルによる次の楽曲の推薦を行います。

ビルドツールやフロントエンドフレームワークは使用していません。

## 動かし方

GitHub リポジトリから以下を取得してください。

```text
data/
ai/model4/
```

最終的に、リポジトリのルートディレクトリが以下のような構成になっていることを確認してください。

```text
matchon/    
 ├── play_history.json
 ├── songs.json  
 ├── model.json  
 ├── player.html  
 ├── server.py  
 └── train.py  
```

リポジトリのルートディレクトリから以下を実行します。

```bash
python3 server.py
```

サーバーが起動したら、ブラウザで以下にアクセスしてください。

```text
http://localhost:8000/
```

これで音楽プレイヤーが起動します。

### 補足

機械学習による選曲には `ai/model4/model.json` のモデルを使用しています。

`data/songs.json` には選曲対象となる音源データが含まれています。

`data/play_history.json` には再生履歴やユーザーによる評価が保存され、機械学習に利用されます。

`server.py` が `data/` のデータを読み込みながら、音楽プレイヤーと選曲機能を提供します。

追加のビルドツールやパッケージ管理ツールは必要ありません。

Python 3 がインストールされていれば実行できます。


## AI に任せなかった部分
「次に何を聴くか」の最終判断は人間に残しました。

AIはユーザーの評価履歴から「次に流すと良さそうな曲」を提案しますが、AIが自動的に再生を決定することはしません。

高評価：今後も流してほしい  
低評価：今後は流してほしくない  
Skip：今は聴かなくてよい  

という3種類の反応を人間が与えます。

これは、部室のように複数人が同じスピーカーで音楽を聴く環境では、AIが「全員にとって正しい曲」を判断することは難しいと考えたためです。

AIには選曲の負担を減らしてもらい、最後に「これは今聴きたい」と決める権利は人間に残しました。
