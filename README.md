# matchon

部室で再生ボタンを押すだけ。好き・嫌い・今は違うを学習して、次に流す曲を提案する音楽プレイヤー。

## 何を作ったか
部室でBGMを流したい人の「次に何を流すか考える手間」を減らす音楽プレイヤーです。
曲を再生して、高評価・低評価・Skip の3つの反応をするだけで、その人の好みを学習します。
学習したデータをもとに、AIが次に流す曲を提案します。
「何を聴くか」という最後の判断は人間に残し、AIが勝手に再生し続けるのではなく、人間とAIが一緒に選曲することを目指しました。


## 使った技術

## 動かし方

GitHub リポジトリから以下のディレクトリを取得してください。

- data/
- ai/model3/

取得したファイルをすべて同じディレクトリに配置します。

最終的に、例えば以下のような構成にします。

soundon/  
├── model.json  
├── play_history.json  
├── player.py  
├── songs.json  
└── train.py  

そのディレクトリで以下を実行します。

python3 player.py

これで音楽プレイヤーが起動します。

補足

機械学習による選曲には ai/model3/ のモデルを使用しています。
data/ には選曲に使用する音源データが含まれています。

追加のビルドツールは必要ありません。


## AI に任せなかった部分
「次に何を聴くか」の最終判断は人間に残しました。

AIはユーザーの評価履歴から「次に流すと良さそうな曲」を提案しますが、AIが自動的に再生を決定することはしません。

高評価：今後も流してほしい  
低評価：今後は流してほしくない  
Skip：今は聴かなくてよい  

という3種類の反応を人間が与えます。

これは、部室のように複数人が同じスピーカーで音楽を聴く環境では、AIが「全員にとって正しい曲」を判断することは難しいと考えたためです。

AIには選曲の負担を減らしてもらい、最後に「これは今聴きたい」と決める権利は人間に残しました。
